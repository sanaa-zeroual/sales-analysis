# 📊 Sales Analysis — Superstore Dataset

> 🚧 **Work in Progress** — This project is actively being developed. More analysis and visualizations coming soon.

A data analysis project built on the classic Superstore sales dataset. The goal is to clean, explore, and analyze sales data to extract meaningful business insights around revenue, products, customers, and regional performance.

---

## 📁 Project Structure

```
sales-analysis/
├── Data/                       # Raw and cleaned datasets
│   └── fixed_superstore.xlsx   # Cleaned Superstore dataset
├── analysis_excel/             # Excel-based analysis files
└── README.md
```

---

## 🔍 About the Dataset

The **Superstore** dataset is a widely used retail sales dataset containing order-level data including:

- Orders, customers, and shipping details
- Product categories and sub-categories
- Sales, profit, quantity, and discount figures
- Geographic data (region, state, city)

---

## 🎯 Analysis Goals

- [ ] Sales and profit trends over time
- [ ] Top-performing products and categories
- [ ] Regional and segment performance comparison
- [ ] Customer analysis and segmentation
- [ ] Discount impact on profitability
- [ ] Dashboard / visualization (coming soon)

## ⚙️ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sanaa-zeroual/sales-analysis.git
cd sales-analysis
```

2. Open `Data/fixed_superstore.xlsx` in Excel or any spreadsheet tool.
3. Explore the analysis files in the `analysis_excel/` folder.
